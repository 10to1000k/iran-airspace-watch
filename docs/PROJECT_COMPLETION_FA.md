# گزارش اتمام پروژه — پایش هوایی ایران

**وضعیت:** تکمیل مرحلهٔ راه‌اندازی و آزمون اولیهٔ لایهٔ شبکه‌های اجتماعی  
**تاریخ:** ۶ آبان ۱۴۰۵ (۲۸ اکتبر ۲۰۲۶)

## آنچه تحویل شد

- منابع RSS خبرگزاری‌ها و GDELT به مسیر جمع‌آوری → فیلتر ربط → دسته‌بندی → ترجمه → ارسال تلگرام متصل‌اند.
- ابهام واژهٔ فارسی «باند» اصلاح شد تا عبارت‌هایی مانند «باند سارقان» به اشتباه خبر فرودگاهی نشوند؛ تست بازگشتی افزوده شد.
- RSSHub و Redis به‌عنوان سرویس‌های داخلی در همان OpenShift namespace مستقر شدند؛ سرویس عمومی برای RSSHub ایجاد نشده است.
- فیدهای Anadolu Agency در X و Instagram به‌عنوان پایلوت به کالکتور RSS پروژه اضافه و فعال شدند.
- دریافت هر دو مسیر از داخل شبکهٔ کلاستر با HTTP 200 مشاهده شد. فید Instagram هنگام آزمون ۳۳ آیتم بازگرداند.
- تنظیمات نامزد برای حساب‌های دیگر اضافه شده‌اند اما تا آزمون جداگانه غیرفعال‌اند.
- ترجمه، دسته‌بندی، فیلتر خبرهای نامرتبط و ارسال تلگرام در مسیر اصلی بدون تغییر باقی مانده‌اند.

## معماری مسیر اجتماعی

`X / Instagram → RSSHub داخلی → Redis cache → RSSCollector بات → فیلتر و دسته‌بندی → ترجمه → تلگرام`

## نتیجهٔ آزمون

- ۱۱۲ تست خودکار پروژه موفق بوده‌اند.
- `git diff --check` بدون خطا بوده است.
- در اجرای زنده، لاگ RSSHub برای فید Anadolu در هر دو پلتفرم پاسخ ۲۰۰ نشان داده است.
- کالکتور RSS بات اجرا شده و درخواست‌های X و Instagram را از سرویس داخلی دریافت کرده است.

## محدودیت‌ها و نکات عملیاتی

- مسیرهای RSSHub برای X و Instagram مبتنی بر وب/نشست هستند، نه API رسمی؛ ممکن است با تغییرات پلتفرم، انقضای نشست یا محدودیت ضدربات از کار بیفتند. اعتبار نشست باید در Secret کلاستر نگه‌داری و در صورت لزوم به‌روزرسانی شود؛ هرگز آن را در Git یا گفت‌وگو منتشر نکنید.
- حساب‌های Anadolu عمومی و چندموضوعی‌اند؛ فیلتر موضوعی بات باید فقط خبرهای مرتبط با ایران و هوانوردی را عبور دهد. نتیجهٔ انتشار را در لاگ‌ها و پیام‌های تلگرام زیر نظر بگیرید.
- در راه‌اندازی، GDELT یک پاسخ HTTP 429 داده است. این منبع مکمل است و این خطا مسیر RSSHub را متوقف نمی‌کند؛ اگر تکرار شد، کاهش فراوانی یا خاموش‌کردن موقت GDELT را بررسی کنید.
- بات دستور تلگرامی `/restart` ندارد. `/start` فقط اشتراک را ثبت می‌کند؛ ری‌استارت سرویس از OpenShift با `oc rollout restart deployment/airwatch` انجام می‌شود.
- سرویس‌های اجتماعی روی همان OpenShift موجود نصب شدند؛ برای پایلوت میزبان جداگانه‌ای لازم نشد.

## وضعیت

پایلوت اجتماعی راه‌اندازی و اعتبارسنجی شده است. گسترش به منابع دیگر باید پس از آزمون مستقل هر مسیر و بازبینی دقت/نویز انجام شود.
