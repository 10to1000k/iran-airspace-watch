# Iran Airspace Watch

پایشگر ۲۴ساعته‌ی اخبار حریم هوایی ایران، فرودگاه‌های مهرآباد و امام خمینی، و ایرلاین‌های مرتبط با ایران.

بات پیدا می‌کند → ترجمه می‌کند به فارسی → همان لحظه در چت خصوصی تلگرام می‌فرستد، همراه با **منبع اصلی** و **برچسب اطمینان**.

---

## وضعیت فعلی

| بخش | وضعیت |
|---|---|
| NOTAM (دیکودر + کالکتور) | ✅ آماده، نیاز به اعتبارنامه‌ی FAA |
| RSS رسانه‌های ۴ کشور + ایران + هوانوردی | ✅ آماده |
| دسته‌بندی و فیلتر ربط | ✅ آماده |
| دِداپ و رشته‌ی رخداد | ✅ آماده |
| ترجمه با گلوساری هوانوردی | ✅ آماده، نیاز به کلید LLM |
| ارسال DM + دکمه‌های بازخورد | ✅ آماده |
| کانال‌های تلگرام (Telethon) | 🟡 اسکلت آماده، نیاز به `api_id/hash` |
| توییتر (twscrape) | 🟡 اسکلت آماده، پیش‌فرض خاموش |
| لیست زنده‌ی ایرلاین‌ها (OpenSky) | 🟡 اسکلت آماده، نیاز به اکانت OpenSky |

## تنظیمات

```powershell
Copy-Item .env.example .env
notepad .env
```

حداقلِ لازم:

- `TELEGRAM_BOT_TOKEN` — از [@BotFather](https://t.me/BotFather)
- یک کلید LLM سازگار با OpenAI (`LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`)

بعد از ساخت بات، **یک بار** در تلگرام به بات `/start` بفرست. بات تلگرام نمی‌تواند شروع‌کننده‌ی چت باشد؛ این تنها کار دستیِ راه‌اندازی است. `chat_id` خودکار ذخیره می‌شود.

## اجرا

```powershell
# تست کامل بدون ارسال چیزی به تلگرام
python run.py --once --dry-run

# بررسی سالم بودن فیدهای RSS
python run.py --check-sources

# دیکود کردن یک NOTAM
python run.py --decode-notam "A1234/26 NOTAMN Q) OIIX/QFALC/IV/NBO/A/000/999/3535N05121E A) OIIX B) 2601011200 C) 2601011800 E) AD CLSD"

# ارسال یک پیام نمونه به چت
python run.py --test-message

# اجرای دائمی
python run.py
```

## معماری

```
collectors ──► classify ──► cluster/dedupe ──► translate ──► format ──► telegram DM
  NOTAM          دسته/شدت      رشته‌ی رخداد      گلوساری       HTML       + دکمه بازخورد
  RSS             + ایرلاین     قفل اثر انگشت     + اعتبارسنجی اعداد
  Telegram
  X/Twitter
```

- **یک پیام به ازای هر رخداد:** اولین منبع فوراً می‌فرستد، تأییدهای بعدی به‌صورت ریپلای در همان رشته می‌آیند و پیام ریشه ادیت می‌شود.
- **قفل اثر انگشت:** جلوگیری از ارسال دوبل وقتی دو کالکتور همزمان یک خبر را می‌بینند.
- **برچسب اطمینان:** `✅ دو منبع مستقل` / `⚠️ تک‌منبع` / `📢 منبع رسمی`.

## تنظیم حساسیت (مهم‌ترین بخش)

فیلتر پیش‌فرض سخت‌گیر است: هر خبر باید **هم نام ایران** و **هم زمینه‌ی هوانوردی** داشته باشد. این عمدی است — در تست واقعی، بدون این قاعده، خبرهای ورزشی و شهری ایران هم رد می‌شدند.

در `config/settings.yaml`:

| چه می‌خواهی | چه کار کنی |
|---|---|
| خبرهای ژئوپلیتیک ایران (جنگ، حمله، موشک، تحریم) هم بیاید | `include_iran_conflict_context: true` |
| پوشش بیشتر، نویز بیشتر | چند مورد از `strong_aviation_keywords` را حذف کن |
| فقط خبرهای قطعی هوانوردی | `include_iran_conflict_context: false` (پیش‌فرض) |
| ایرلاین جدید اضافه کن | `config/airlines.yaml` |

قاعده‌ی ضدنویز که پیاده شده: «پرواز» تنها کافی نیست (خبر ورزشی: «پرواز تیم ملی به فینال»)، و کدهای کوتاه ایرلاین فقط با حروف بزرگ معتبرند (وگرنه «IS» با فعل is و «SAW» با saw قاطی می‌شود).

## وضعیت منابع

همه‌ی فیدها در تاریخ ۱۴۰۵/۰۷/۲۹ تست شدند. منابعی که RSS فعال ندارند (Khaleej Times، The National، Al Bayan، WAM، China Daily، Caixin، Aviation Herald، Gazete Duvar، RBC) با `enabled: false` نگه داشته شده‌اند تا بعداً دوباره بررسی شوند. با `--check-sources` وضعیت را ببین.

## محدودیت‌ها و ریسک‌ها

- **NOTAM:** API رسمی FAA نیاز به ثبت‌نام و کلید دارد. منابع غیررسمی پایدار نیستند و در کد تعبیه نشده‌اند.
- **توییتر و اینستاگرام:** اسکرپینگ خلاف شرایط سرویس آن‌هاست و می‌تواند به مسدود شدن حساب/آی‌پی منجر شود. پیش‌فرض خاموش است.
- **ترجمه‌ی ماشینی** ممکن است عدد یا نام را جابه‌جا کند. اعتبارسنجی اعداد انجام می‌شود ولی جای بازبینی انسانی را نمی‌گیرد. برچسب «نیازمند بازبینی» را جدی بگیرید.
- **کپی‌رایت:** همیشه خلاصه + لینک + ذکر منبع، نه بازنشر کامل متن یا تصویر.
- **اعتبار منابع:** تاس، ریانووستی و شینهوا رسانه‌ی دولتی‌اند؛ مدوزا و بیانِت مستقل. این تفاوت در برچسب منبع دیده می‌شود.
- **لیست ایرلاین‌ها فرضیه است:** `config/airlines.yaml` نقطه‌ی شروع است، نه واقعیت روز. با `--build-watchlist` از داده‌ی واقعی پرواز تأییدش کنید.
